# 如何使用这个知识库

## 找到内容

你可以通过顶部导航进入教程、笔记和资源，也可以直接使用搜索框。搜索会在浏览器本地完成，不会把关键词发送给第三方服务。

## 内容分类

- **系统教程**：围绕一个明确目标组织的完整实践。
- **日常笔记**：对问题、想法和短期经验的结构化记录。
- **资源清单**：经过筛选并带有用途说明的外部资料。

## 新增文档

1. 选择合适目录并创建小写英文文件名。
2. 填写标题、描述、日期和标签。
3. 用二级标题组织内容，并给出能够验证结果的方法。
4. 本地运行构建，确认链接、搜索和排版正常。
5. 提交并推送到 GitHub；合并到 `main` 后自动发布。

::: tip 地址稳定性
文章发布后尽量不要改文件名。确需改名时，在仓库根目录的 `redirects.json` 中添加“旧地址 → 新地址”，构建会生成重定向页并随网站一起发布。
:::
